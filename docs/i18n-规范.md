# VibeDrop 多语言(i18n)施工规范

> 本文是翻译施工的**唯一契约**。骨架(i18n.js / 质检门 / 本文)已定型,施工只做两件事:
> ① 给代码里的中文包上 `t()` ② 填语言包 JSON。**不要改 i18n.js,不要发明新机制。**

## 流派:中文原文即钥匙(gettext 式)

- 钥匙就是界面上的中文原句,**不发明英文键名**。
- 缺译自动回退中文原文,界面永不空白 → **改一半也可随时发布**。
- 中文文案本身变更时,语言包里对应键要同步改(质检门会报出来)。

## JS 动态文案

```js
// 改造前
showToast('图片已放入 Mac 剪贴板');
// 改造后
showToast(t('图片已放入 Mac 剪贴板'));
```

**带变量的句子必须用占位符,严禁字符串拼接**(词序在别的语言里会变):

```js
// 错误 ✗
showToast('已改名为 ' + newName);
// 正确 ✓
showToast(t('已改名为 {name}', { name: newName }));
// en.json → "已改名为 {name}": "Renamed to {name}"
```

规则:
1. 钥匙必须是**字面量字符串**,不许用模板字符串/变量当钥匙(质检门扫不到)。
2. 模板字面量里的中文照样包:`` `<span>${t('已连接')}</span>` ``。
3. 只包**用户可见**的文案;日志(debugLog/console)、协议字段、CSS 类名不包。
4. Rust 层(lib.rs/main.rs)的文案本期不动。

## HTML 静态文案

```html
<!-- 元素文本 -->
<h3 data-i18n>智能发送卡</h3>
<!-- placeholder / title 属性 -->
<textarea placeholder="输入要发送的文字..." data-i18n-placeholder></textarea>
<button title="消息时间显示时区" data-i18n-title>…</button>
```

只加属性标记,**不改中文原文**。含子元素的复合节点不要挂 data-i18n(会吞掉子元素),改由 JS 渲染处包 t()。

## 语言包

- 位置:`mobile/src/locales/<lang>.json`、`desktop/src/locales/<lang>.json`
- 格式:平面 JSON,`"中文原句": "译文"`,按中文排序,UTF-8 无转义。
- 新语言 = 新增一个文件,不改任何代码。

## 同步纪律(仓库既有规矩)

mobile/src 的 app.js、index.html、style.css、i18n.js、locales/ 改完必须同步拷贝到 desktop/static/。

## 质检门(每轮施工后必跑)

```bash
python3 scripts/i18n-check.py
```

- `缺:` = 代码里有钥匙、语言包没译 → 必须补齐到零
- `冗余:` = 语言包有、代码里已不存在 → 删掉
- 全绿标准:每个语言包 缺 0。

## 验收定义

1. `i18n-check.py` 全绿;
2. `node --check` 通过 mobile/src/app.js 与 desktop/static/app.js;
3. 系统语言为中文时界面与改造前**逐像素一致**(中文是源语言,不查表);
4. 设置里切 English → 界面全英文,无残留中文、无 `{name}` 这类未替换占位符。

## 新增语言施工须知(2026-08 批次:zh-TW / ja / ko / es / fr / de)

1. **一律从中文原文直译**,不要从 en.json 转译(二手翻译叠加损耗)。
2. 每门语言产出两个文件:`mobile/src/locales/<lang>.json` 与 `desktop/src/locales/<lang>.json`,键集合与 en.json 完全一致(以质检门为准)。
3. 星期几单字钥匙("一"~"日")按该语言惯例填(日语:月火水木金土日;韩语:월화수목금토일)。
4. 日期格式钥匙(如 `{year}年{month}月`)按该语言数字日期惯例填,占位符原样保留。
5. UI 空间紧张,译文**宁短勿长**(德语尤其注意按钮文案长度)。
6. 语言选择器里的语言名是**语言自称**,任何语言包都不翻译它们。
7. 完工标准:`python3 scripts/i18n-check.py --strict` 全绿 + mobile 的 i18n 全家(app.js/index.html/style.css/i18n.js/locales/)同步拷贝到 desktop/static/。

## 语义验收(每门新语言必过,2026-08-18 定为固定流程)

机器质检只保格式,保不了语义。每门语言交付后必须由验收方**逐句精读约 30 个核心界面词**
(发送/回车/发送并回车/传图到剪贴板/传到收件箱/历史/设置/跟随系统/智能发送卡/搜索/来源/目标/
类型/时间/本机/全部/已连接/未连接/保存/取消/关闭/删除/刚刚/今天/语言/发送失败/附近电脑 等),
并跑可疑模式扫描(译文==原文、译文==英文照抄)。

历史战果证明其必要:韩语曾把"传输历史"译成 이체 내역(银行转账明细)、法语把筛选标签"类型"
译成动词 Tapez(请打字)——全部是质检门全绿状态下的真错译,只有人读才能抓到。
